# CD Sim documentation

CD Sim is Chakravyuha Dynamics' offline-first, platform-agnostic mission-rehearsal,
training and simulation platform, built on Unreal Engine 5.

> **Status: Phase 0 (skeleton) — under build.** RAVEN is CDPL's only delivered
> programme; nothing documented here is fielded. See the [Roadmap](10_ROADMAP.md).
